## Before you implement

- The inherited API specification publishes the `travelCoverage` and `traveller` schemas and no endpoints. The surface here mirrors the motor pattern over those schemas, and introduces no new entity schema.

## Market profiles

This module is market-neutral. Nothing it defines varies by market, so no profile constrains it.
