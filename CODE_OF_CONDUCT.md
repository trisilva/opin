# Code of conduct

## The standard

Be civil and argue about the work. Disagreement is the point of an open standard, and a well-argued
objection is the most valuable thing anyone brings here.

Not acceptable: harassment, personal attacks, discriminatory language, or sustained disruption of a
discussion. Not the same thing: telling a maintainer they are wrong, at length, with evidence. The
second is welcome and the process is built to expect it.

## Scope

Issues, pull requests, discussions and any other space this project uses.

## Reporting

Email an editor listed in [`MAINTAINERS.md`](MAINTAINERS.md), or open a private vulnerability
report if you would rather not use email.

Reports are read by the editors. A report about an editor is a real difficulty in a project this
small, and it is worth saying plainly that there is no independent body to escalate to yet. If that
matters to you, say so in your report and it will be handled with whatever independence can be
arranged.

## Enforcement

A warning, then a temporary block, then a permanent one. Editors decide, and a decision here gets a
written reason like every other decision in this project.
